# Supply Chain Delivery Performance Analysis

## Project Review

This project analyses e-commerce supple chain operations to identify late delivery patterns, investigate operational bottlenecks, evaluate profitability, and develop a machine learning model to predict late-delivery risk.

The objective is to support data-driven decisions that improve delivery performance, customer satisfaction, and operational efficiency.

## Business Objectives 

- Analyse on-time and late-delivery performance.
-Identify delivery bottleneck across
shipping modes and regions.
-Evaluate order profitability and profit associated with delayed orders.
-Identify time-based delivery patterns.
-Build a machine learning model to predict late-delivery risk.
-Recommend business improvements based on analytical findings.

## Key Findings

| Metric | Result |
|----|---:|
| Total Orders Analysed | 172,765 |
| Late-Delivery Rate | 54.71% |
| On-Time Delivery Rate | 45.29% |
| Total Reported Profit | $7.5M |
| Profit Associated with Delayed Orders | $2.1M |
| Random Forest Accuracy | 74% |

## Machine learning

A Radom forest classifier was developed to predict
late-delivery risk.

Reported test-set results:

- Accuracy:74%
- Precision for late orders : 0.78
- Recall for late orders : 0.75 
- F1-score for late orders : 0.77

## Business Recommendations

- Audit First Class and Second Class delivery performance.
- Investigate payment-review bottlenecks.
- Pilot predictive alerts for high-risk orders.
- Improve seasonal logistics and capacity planning.
- Monitor delivery performance and profitability KPIs.
